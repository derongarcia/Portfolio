SMS Classification

A Natural Language Processing project that classifies SMS messages into different categories, such as spam, scam, and promotional messages. The project focuses on processing and analyzing text data to automatically identify potentially unwanted messages.
I was responsible for designing and experimenting with the text preprocessing pipeline. I compared WordNetLemmatizer, stemming, and Sastrawi to evaluate how different preprocessing techniques affected the classification performance.
I also using a custom slang dictionary to handle informal Indonesian expressions commonly used in SMS messages. The dictionary was integrated into the preprocessing pipeline to normalize slang words before feature extraction. I then evaluated the results of each preprocessing approach and identified the approach that provided the best performance for the classification model.

Simple Python Game

A simple console-based Python project featuring two mini games. The first game, CUYPY Games, challenges players to guess which cave contains the animal named CUYPY by choosing a number from 1 to 4. The second game is a word guessing game where players guess a hidden word by entering one letter at a time.
I designed and developed the game logic using Python. I implemented functions using def to separate different parts of the program and make the code easier to manage and reuse.
I also organized the project into multiple modules and folders instead of putting the entire program in a single file. The main.py file handles the main menu and program flow, while the CUYPY and word guessing games are separated into their own modules. The program uses imports to connect functions and modules across different folders. I also implemented a main guard using if name == ' main ' : to ensure the main program only runs when the file is executed directly.
